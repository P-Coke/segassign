SegAssign 2.1.0 Windows x64
============================

启动方式
--------
完整解压后双击 SegAssign.exe，保留同目录的 _internal 文件夹。
本程序是遥感科研项目的配套自动化工具；源代码采用 MIT 协议，第三方运行库保留各自许可。

00 分割并赋值 / 01 单独分割
-------------------------
1. 需要本机已安装并授权的 eCognition Developer 9；请在界面中选择其安装目录。
   eCognition SDK 和许可证不会打包进本程序。
2. 亚米级影像、2 米基础影像和分类影像均支持选择单个 GeoTIFF 或文件夹进行批量处理。
   - 基础影像或分类影像选择单文件时，所有待分割影像共用该文件。
   - 选择文件夹时，程序按“相对路径 -> 同名 -> 最大空间重叠面积”自动配对，输出至目标目录并保留相对子目录结构。
   - 批处理输出目录应与所有输入目录分开，不可位于输入目录内部。
3. TIFF 读取失败时程序会重新打开文件重试（最多共 3 次），持续失败会报告具体影像、tile 与读取窗口。

02 单独赋值
-----------
1. 输入矢量可选择单个 .shp，也可选择文件夹；选择文件夹时递归发现全部 Shapefile。
2. 分类影像选择当前区域的一幅 GeoTIFF，例如区域 A。
3. 输出选择目录，成果保持原文件名和相对子目录结构。
4. 区域 A 输出目录可直接作为下一次输入，换成区域 B 分类影像即可二次赋值。
5. 当前分类影像无有效像元覆盖的要素会保留已有 class/v1/v1p... 字段值。
6. 跨越 A/B 的同一要素会通过同名 .gtz.npz 旁车累计两区原始像元计数；请勿单独删除该文件。
7. A/B 的分类编码及像元面积需一致、有效区域不重叠；重复或重叠区域不会自动去重。
8. 两次赋值之间请保持矢量几何和要素顺序不变。

硬件自适应调优与缓存管理
------------------------
1. 启动时程序自动识别本机物理核心、实时可用内存与磁盘类型，默认优先使用剩余空间充足的非系统高速盘（NVMe/SATA）作为缓存盘。
2. 右侧“硬件自适应调优”提供低占用 / 自动最优 / 高性能三档，推荐保持“自动最优”。
3. 右侧“高速缓存管理”支持查看占用、更换缓存盘与一键清理缓存，并默认勾选“完成后自动清理缓存”：
   - 运行中每块瓦片后处理完成后即时释放原始导出临时文件；
   - 任务成功后自动删除全部大体积中间缓存，仅在缓存目录 reports/ 下归档极小运行报告；
   - 任务中断、失败或取消时自动保留断点数据，勾选“断点续跑”并保持相同输入与参数即可继续执行；
   - 超过 7 天未使用的过期缓存将在下次启动时自动回收。
