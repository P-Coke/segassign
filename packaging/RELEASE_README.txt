SegAssign 2.0.2 Windows x64
============================

启动方式
--------
完整解压后双击 SegAssign.exe，保留同目录的 _internal 文件夹。
本程序是遥感科研项目的配套自动化工具；源代码采用 MIT 协议，第三方运行库保留各自许可。

2.0.1 影像读取修复
-----------------
夏季或冬季 TIFF 读取失败后，程序会重新打开文件重试，最多共 3 次。
持续失败时，报告记录具体影像路径、tile、读取窗口和底层错误，不以 0 填充或跳过坏数据。
准备阶段异常后，已完成的 eCognition tile 会保存断点。如需复用旧断点，请关闭旧版后
在原程序目录更新，保留原输出目录下的 .geotoolbox-work，选择相同输入及参数并勾选
“断点续跑”。更换程序/输入路径或输入指纹变化会使相关缓存失效。
若客户文件本身截断或损坏，重试无法修复缺失的字节，需要重新拷贝或重新导出完整源数据。

02 单独赋值
-----------
1. 输入矢量可选择单个 .shp，也可选择文件夹；选择文件夹时自动发现全部 Shapefile。
2. 分类影像选择当前区域的一幅 GeoTIFF，例如区域 A。
3. 输出选择目录，成果保持原文件名和相对子目录结构。
4. 工作目录由程序自动管理，无需配置。
5. 区域 A 输出目录可直接作为下一次输入，换成区域 B 分类影像即可二次赋值。
6. 当前分类影像无有效像元覆盖的要素会保留已有 class/v1/v1p... 字段值。
7. 跨越 A/B 的同一要素会通过同名 .gtz.npz 旁车累计两区原始像元计数；请勿单独删除该文件。
8. A/B 的分类编码及像元面积需一致、有效区域不重叠；重复或重叠区域不会自动去重。
9. 两次赋值之间请保持矢量几何和要素顺序不变。

01/00 分割要求
--------------
需要本机已安装并授权的 eCognition Developer 9；请在界面中选择其安装目录。
eCognition SDK 和许可证不会打包进本程序。

运行数据、结果与报告
--------------------
程序不包含业务数据。赋值运行报告和断点数据位于输出目录下的 .geotoolbox-work。
