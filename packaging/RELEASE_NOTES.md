# SegAssign 2.1.0

遥感科研项目配套自动化工具的功能与性能升级版本，新增全流程文件夹批处理、硬件自适应调优与四层生命周期缓存管理。

## 本次更新

- **00/01 文件夹批处理**：亚米级影像、2 米基础影像与分类影像均支持单文件或文件夹输入；单文件全局共用，多目录按相对路径、同名与最大空间重叠面积自动配对并保留输出相对目录结构。
- **分割拼接与流水线加速**：
  - 引入接缝带精确过滤（`seam_band`）与内部 `FlatGeobuf (.fgb)` 瓦片缓存，显著加速大幅面矢量拼接并保持几何与面积一致。
  - 增加全局有效像元粗扫与行内 LPT 调度、跨行背压及批处理跨景首行预取流水线。
  - 分类赋值批处理共享工作进程池并复用分类像元值扫描；移除冗余 `scipy` 依赖和历史旧代码。
- **硬件自适应与缓存策略**：
  - 自动探测物理核心数、实时可用内存与本机磁盘类型（优先非系统盘 NVMe/SATA），自动匹配并发预算与中图瓦片尺寸。
  - 支持执行期即时释放 `ObjectShapes.shp`、任务成功后自动清理临时缓存（仅归档轻量报告）、失败/取消保留断点续跑、启动回收 7 天过期缓存及界面一键手动清理。
- **响应式桌面界面**：修复不同分辨率下的纵向压缩与控件重叠问题，新增“硬件自适应调优”和“高速缓存管理”面板。

## 使用说明

Windows 用户请完整解压 `SegAssign-v2.1.0-Windows-x64.zip` 并运行 `SegAssign.exe`，保留 `_internal` 目录。`00/01` 分割要求本机安装并授权 eCognition Developer 9；`02` 赋值无需该软件。

跨区域赋值时请保留 `.gtz.npz` 及 Shapefile 伴随文件，区域分类编码与像元面积需一致、有效区域不重叠，重复输入不会自动去重。断点续跑需要保持输入路径与核心参数一致；任务中断或取消后自动保留断点现场，成功后默认自动清理中间缓存。
