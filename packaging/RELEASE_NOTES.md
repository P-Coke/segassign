# SegAssign 2.2.0

遥感科研项目配套自动化工具的全新导航式向导与高吞吐尾段并行调度版本。

## 本次核心更新

- **三步导航式界面（简明直白）**：
  - **① 参数配置**：保留熟悉的 `00 分割并赋值`、`01 单独分割`、`02 单独赋值` 入口，支持文件/文件夹切换与拖放路径，启动自动侦测本机 eCognition 9 目录与最快空闲 SSD 缓存盘。
  - **② 清单确认**：点击下一步自动扫描并配对全部待处理栅格/矢量，以表格形式呈现规格、配对关系与输出路径，默认全部勾选，支持灵活勾选筛选与参数核对。
  - **③ 进度监控**：顶部展示总体进度条、实时 `CPU / RAM` 占用与已用/预计剩余时间（ETA）；左侧为每个待处理文件提供独立进度条、实时阶段与耗时；右侧新增超轻量 **GIS 空间切片实时预览视窗**，以矢量边界实时展示影像/矢量切片范围与处理状态（未处理红 / 处理中蓝 / 已完成绿 / 空区灰），点击表格行即可切换查看对应景的切片分布。
- **跨景尾段提前启动 + 动态 90% 调优引擎**：
  - `00/01` 批量处理使用全局共享并发池与 `DynamicAutoTuner`（动态追踪 ~90% CPU/RAM，内存达 90% 立即回退防 OOM）；当前一景进入尾段或系统算力释放时自动提前启动下一景，`02` 批量赋值同步实现尾段计数与写入重叠，大幅压低多文件批处理总耗时。
  - 全面压缩 UI 批量刷新、子进程轮询与内存采样等非核心开销，并自动调优 `GDAL_CACHEMAX` 块缓存。
- **四层生命周期缓存**：执行期即时释放 `ObjectShapes.shp`、成功后自动清理全部临时缓存仅归档轻量报告、失败/取消保留断点续跑、超 7 天过期自动回收。

## 使用说明

Windows 用户请完整解压 `SegAssign-v2.2.0-Windows-x64.zip` 并运行 `SegAssign.exe`，保留 `_internal` 目录。`00/01` 分割要求本机安装并授权 eCognition Developer 9（程序将自动侦测，也支持手动选择安装根目录或 `bin`）；`02` 赋值无需该软件。

## 验证摘要

- 79 项单元与回归测试（`pytest`）全部通过，涵盖三步向导交互、GIS 空间切片预览视窗、单文件独立进度条、跨景尾段提前启动并发、勾选过滤、动态 90% 调优与 eCognition 自动侦测。
- `ruff` 静态检查 0 错误；冻结版 EXE 启动与 GIS 批处理冒烟测试通过；全部 3 个向导界面均通过实机渲染核验。
